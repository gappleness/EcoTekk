# EcoTekk ♻️

EcoTekk helps users troubleshoot electronic devices, find repair services, and locate e-waste recycling facilities.

## Features
- Device troubleshooting
- Repair shop locator
- E-waste drop-off locator
- User accounts
- Preparation checklist
- Light and dark mode

## Technologies
- HTML, CSS, JavaScript
- Firebase
- Google Maps
