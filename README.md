# EcoTekk ♻️

**EcoTekk** is a web-based platform designed to help users find nearby e-waste drop-off locations and encourage responsible electronic waste disposal.

### Features
- Find nearby e-waste drop-offs, filterable by accepted waste type, site type, quantity and coverage (approximate matches, with closest-match fallback)
- Tech Help: nearby repair shops and service centers
- Both finders share the same layout and a community "I went here" tally (display only; never changes ranking)
- Guest mode: use every tool with a basic display (no saved profile or customization)
- View locations on Google Maps and get directions
- Sign in with Google or email using Firebase
- Personal profile and dark mode

### Built With
